# SaveFood

Aplicativo mobile híbrido desenvolvido com Expo e React Native, inspirado no modelo do Too Good To Go para combate ao desperdício de alimentos.

## Integrantes da Dupla
* Yago Jardim
* Caio

## Tecnologias
* React Native
* Expo

## Como rodar o projeto

1. Instale as dependências:
```bash
npm install
```

2. Execute o servidor de desenvolvimento:
```bash
npx expo start
```

* Para testar no celular, leia o QR Code usando o aplicativo **Expo Go**.
* Para testar no navegador, pressione `w` no terminal.
